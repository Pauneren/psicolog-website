2. Datos personales que podemos recopilar

A través de este sitio web podemos recopilar datos personales cuando el usuario completa un formulario de contacto, envía un correo electrónico, utiliza un botón de WhatsApp o se comunica por otros medios disponibles.

Los datos recopilados pueden incluir:

  • Nombre y apellido.
  • Correo electrónico.
  • Número de teléfono.
  • Mensaje o consulta enviada por el usuario.
  • Información técnica básica derivada del uso del sitio web, como dirección IP, navegador o dispositivo, en caso de utilizar herramientas de análisis.

El formulario de contacto está pensado únicamente para consultas generales, solicitudes de información o coordinación de turnos. No debes incluir información clínica sensible (por ejemplo, diagnósticos, historias clínicas detalladas, medicación, situaciones de crisis o datos de terceros) a través de este medio. Este formulario no reemplaza una consulta profesional ni debe utilizarse para emergencias. En situaciones de urgencia, acudé a los servicios de emergencia o salud correspondientes en tu localidad.

3. Finalidad del tratamiento

Los datos personales facilitados serán utilizados únicamente para las siguientes finalidades:

  • Responder consultas enviadas por el usuario.
  • Gestionar solicitudes de información, turnos, presupuestos o servicios.
  • Mantener la comunicación con el usuario cuando sea necesario.
  • Mejorar el funcionamiento, seguridad y experiencia de navegación del sitio web.
  • Cumplir con obligaciones legales aplicables, si correspondiera.

4. Base legal para el tratamiento

La base legal para el tratamiento de los datos personales es el consentimiento del usuario, otorgado al completar formularios, enviar mensajes, comunicarse por correo electrónico, WhatsApp u otros canales disponibles en el sitio.

En algunos casos, el tratamiento también puede ser necesario para la ejecución de una relación contractual o precontractual, o para el cumplimiento de obligaciones legales.

5. Conservación de los datos

Los datos personales serán conservados durante el tiempo necesario para cumplir con la finalidad para la cual fueron recopilados, responder consultas, mantener la relación con el usuario o cumplir con obligaciones legales.

Una vez que los datos ya no sean necesarios, serán eliminados o anonimizados cuando corresponda.

6. Comunicación de datos a terceros

No venderemos, alquilaremos ni cederemos los datos personales del usuario a terceros, salvo obligación legal o cuando sea necesario para prestar un servicio solicitado por el usuario.

Este sitio puede utilizar servicios de terceros, como plataformas de alojamiento web, formularios, herramientas de análisis, mapas, correo electrónico, WhatsApp o redes sociales, que pueden tratar datos conforme a sus propias políticas de privacidad.

7. Servicios de terceros

El sitio web puede contener enlaces o integraciones con servicios externos, tales como Google Maps, Google Analytics, WhatsApp, redes sociales, formularios de contacto u otras herramientas.

El formulario de contacto puede utilizar un servicio de terceros para el envío de mensajes, como Formspree u otra plataforma similar de procesamiento de formularios. En ese caso, los datos que envíes (nombre, correo, teléfono y mensaje) pueden ser transmitidos y almacenados temporalmente por dicho proveedor con el fin de reenviarlos por correo electrónico. El tratamiento por parte de ese tercero se rige por su propia política de privacidad y condiciones de uso.

La Licenciada Julieta Banco no controla íntegramente la infraestructura de proveedores externos; se procuran medios razonables para la comunicación, pero no se garantiza un nivel de seguridad equivalente al de un canal clínico reservado. Por eso se recomienda no enviar por este formulario información clínica sensible.

El uso de estos servicios puede implicar el tratamiento de datos por parte de dichos terceros. Recomendamos revisar sus respectivas políticas de privacidad.
